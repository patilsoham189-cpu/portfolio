# Soham Patil — Developer Portfolio

A modern, high-performance developer portfolio built specifically for **Soham Patil**, highlighting full-stack Java engineering, Spring Boot architectures, enterprise database systems, and consistent algorithmic problem solving.

---

## 🌟 Highlights & Features

- **Personalized Showcase**: Features Soham's authentic profile, full high-resolution portrait, academic achievements (SPPU B.E. Computer Engineering, 8.23 CGPA), and verified badges.
- **Flagship Project Deep Dive**: Detailed breakdown of **GenBank: Core Banking & NetBanking Platform** with interactive architecture modal, JPA `@Version` optimistic locking, and decoupled Python FastAPI OTP verification.
- **LeetCode & Problem Solving Tracker**: Showcases Soham's **100 Days Badge 2026**, **81-day maximum streak**, 55+ solved problems, and HackerRank **3-Star Java** badge.
- **Interactive Developer CLI Terminal**: Built-in interactive console where recruiters and engineers can run commands like `help`, `projects`, `skills`, `leetcode`, `resume`, `contact`, and `sudo hire-soham`!
- **Refined Day & Night Mode**: Clean dual-theme design (crisp Apple/Linear style in Day mode, deep luminous dark mode at Night) with persistent local storage.
- **Embedded Official Logos**: Vector SVGs for GitHub, LinkedIn, LeetCode, and HackerRank rendered cleanly across all browsers.
- **Education Milestones**: Accurate graduation timelines (SPPU B.E. 2027, HSC 12th Completed 2023 at 78.00%, SSC 10th Completed 2021 at 94.80%).
- **Zero Build Friction**: Built with HTML5, Tailwind CSS, and modular vanilla JavaScript. Runs instantly in any web browser without compilation or node dependencies.

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Push this repository to GitHub under `patilsoham189-cpu/portfolio`.
2. Go to **Settings** &rarr; **Pages** &rarr; select `main` branch / root directory `/`.
3. Your live URL will instantly be: `https://patilsoham189-cpu.github.io/portfolio/`.

### 2. Vercel
1. Go to [vercel.com](https://vercel.com) &rarr; "Add New Project".
2. Select your repository and click **Deploy**. No build command required!

### 3. Netlify
1. Drag and drop the `Portfolio` folder directly onto [Netlify Drop](https://app.netlify.com/drop).
2. Live in 5 seconds with a custom subdomain.
